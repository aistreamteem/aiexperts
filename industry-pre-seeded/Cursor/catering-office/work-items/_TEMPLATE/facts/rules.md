# Work Item Rules

Rules are constraints, procedures, and patterns that MUST be followed during this Work Item. They are prescriptive and violations should be logged in the journal.

**Format:**

```
### YYYY-MM-DD: [Label/Title]
**Scope:** work-item
**Captured:** YYYY-MM-DD
**Source:** [Optional]
**Status:** [active | promoted-to-expert | archived]
**Triggers:** none

**Rule:** [statement]

---
```

**Note:** Work Item-level rules do NOT need a `**Workflows:**` field — they inherit this Work Item's catering job.

For Expert Role-level rules (in `facts/rules-operations.md`), include workflow applicability (`all`).
