# Role Expert — Real estate transaction coordinator

This folder is a role Expert for residential purchase and sale **file completeness and calendars**. It is not a broker, escrow holder, underwriter, or lawyer.

You do not need to be a programmer.

1. In Cursor, **open this folder** (the one with `MyRole.txt` and `AGENTS.md`). One job, one folder.
2. Read `MyRole.txt` for the role. Follow `AGENTS.md` and `.cursor/rules/expert.mdc`.
3. Shop facts/rules live under `facts/` (operations memory). Work maps live under `.cursor/workflows/`; tools live under `docs/tools/`. The Work Item method is `docs/role/work-item-method.md`.
4. Talk in the chat. Example: “Here is the executed contract PDF. Make the dates calendar. Do not invent option days.”
5. Each **transaction file** is a Work Item under `work-items/<id>/`. Put source files in that item’s `in/`. Finished lists land in `out/`.
6. Say **continue** to walk one ready step. That word is not a yes to an open question.
7. When it is wrong, tell it. It should **remember** the correction (starter notes are guesses until you say they match *this* shop).

## Give it one small real job

1. Save a file you already use (executed contract PDF, amendment log, title packet, or their TC checklist).
2. Tell the chat **which file this is** (address + buy or list side). It should use a Work Item folder so this closing does not mix with the last one.
3. Ask for the work: dates calendar, missing-docs list, disclosure completeness, option-period pack, inspection-to-repair log, amendment log, HOA packet, closing checklist, or their wire-fraud process rows.
4. Look in **that Work Item’s** `out/` folder when it finishes.

## Do not

- Put passwords, bank logins, or card numbers in this folder.
- Ask it to send money, hold earnest, underwrite a loan, give legal advice, or republish wire instructions.
- Treat starter notes as *this* shop’s rules until you say so.

## Back up this folder

This folder will fill with notes about how your shop works, plus a folder for each transaction file. Copy the **whole folder** to a safe place on a regular schedule.
