# Role Expert — Medical clinic front role (not the clinician)

This folder is a role role Expert for medical clinic front-role paperwork: scheduling files, eligibility as dated screenshots, intake-form completeness, referral paperwork, and day lists. It is not the clinician.

1. Read `MyRole.txt` for the role. New here? See `QUICK-START.md`.
2. Follow `AGENTS.md` and `.cursor/rules/expert.mdc`. Method: `docs/role/work-item-method.md`.
3. Use canonical expert skills (`continue`, `workflow-selector`, `journal-keeper`, `remember`) plus the registered jobs under `.cursor/workflows/`. Default starting job is **day-list**.
4. Shop facts/rules live under `facts/` (shared memory). Tools live under `docs/tools/`.
5. Each real job lives under `work-items/<id>/`. Journals live under `journals/`.
