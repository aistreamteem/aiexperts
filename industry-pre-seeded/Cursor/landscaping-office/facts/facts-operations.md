**Scope:** expert-role
**Workflows:** all
**Captured:** 2026-11-08
**Source:** seeds/landscaping-office/docs/facts/access-gate-code-ask-not-in-docs.md
**Status:** active

**Starter / guess until they teach.**

Access is whether the crew can get onto the property: gate, lockbox, HOA clicker, dock hours, or a dog that must be inside. If their export already dumped a code into a CSV, do not copy it forward; say access notes exist in their system and they must handle codes there. Time windows and “call ahead” flags are fine to list. After-hours or weekend access is their note. You flag missing access. They keep secrets in their own lockbox. Starter until they teach how *this* shop shares clickers without writing numbers into the Expert folder. A holiday or after-hours window is still not a code. If two properties share a clicker in their note, say shared access exists without writing the secret.

## 2026-11-08: How this role files work items
**Scope:** expert-role
**Workflows:** all
**Captured:** 2026-11-08
**Source:** seeds/landscaping-office/docs/facts/how-we-file.md
**Status:** active

**Starter / guess until they teach.**

Day-to-day work does **not** go in one shared pile. Each **work item** gets its own folder under `work-items/<id>/` so Tuesday does not overwrite Monday, and one appointment does not mix with the next.

Typical name for *this* role (until they teach a different pattern):

- **What one folder is:** property + service date or crew day
- **How to name it:** `work-items/2026-09-15-12-oak-mow/`
- **Pattern:** `work-items/YYYY-MM-DD-property-or-crew/` (or a WID- id)

Inside every Work Item folder:

- `in/` — files they dropped for *this* item only
- `work/` — scratch while this item is in progress
- `out/` — the finished list or pack for *this* item
- `evidence/` — check logs for this item only

A crew day board is `work-items/YYYY-MM-DD-crew-a/` if they asked for the route, not one yard.

If they already file another way (their software’s id, a property code, a period name), **use their words**. Ask before starting if it is unclear which item this is. Never dump new files into yesterday’s folder. Never put two appointments, two tickets, or two periods in the same item folder unless they asked for a combined pack and named it that way (for example one day-list).
