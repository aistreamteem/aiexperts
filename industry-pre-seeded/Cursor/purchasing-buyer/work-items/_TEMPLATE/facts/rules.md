# Work Item Rules

Rules that MUST be followed during **this pack**. Violations go in the journal.

**Format:**

```
### YYYY-MM-DD: [Label/Title]
**Scope:** work-item
**Triggers:** none
**Captured:** YYYY-MM-DD
**Source:** [operator, export name, chat]
**Status:** [active | promoted-to-expert | archived]

**Rule:** [statement]
```

Work Item rules do not need a `**Workflows:**` field — they inherit this pack’s workflow. Include `**Triggers:**` so promoted rules already carry the field.

Expert Role rules: `facts/rules-shared.md` (`Workflows: all`) and `facts/rules-operations.md` (job-specific).
