# Role Expert — HOA / association admin

This folder is an AI Expert for community-association admin work (violations, ACC completeness, dues aging, board files, bids, vendor certificates, work orders, election tallies, reserve-study presence).

You do not need to be a programmer. Notes already here are a **head start** — typical for this kind of role, not how *your* association works, until you say otherwise.

1. Open **this** folder in the chat product (the folder that contains `MyRole.txt` and `AGENTS.md`). One job, one folder.
2. Read `MyRole.txt` for the role. Follow `AGENTS.md` and `.cursor/rules/expert.mdc`.
3. How a job runs: `docs/role/work-item-method.md`. Registered jobs live under `.cursor/workflows/`. Shop facts/rules live in `facts/facts-operations.md` and `facts/rules-operations.md`. Tools live under `docs/tools/`.
4. Give it one small real job: save a file you already use (ledger export, ACC form, bid PDF, roster). Say which job this is (this week’s ACC packet, the June board meeting, lot 12’s open violations). It should make a folder under `work-items/` so this work does not mix with the last job. Put the file in that folder’s `in/` directory.
5. Ask for the work. Example: “Here is this week’s ledger export. Make the dues aging list. Do not invent numbers that are not in the file.”
6. When it finishes, look in **that Work Item’s** `out/` folder.
7. When it is wrong, tell it. It should **remember** the correction. A few real jobs plus a few corrections is enough to get going.

Canonical skills: `continue`, `workflow-selector`, `journal-keeper`, `remember`, `operator-qa`, `promote-facts-rules`, `switch-context`, `integrate-docs`, `memory-optimize`, `visual-page`, `define-role`.

## Do not

- Put passwords, bank logins, or card numbers in this folder.
- Ask it to send money or pay a bill.
- Ask it to be a lawyer, engineer, or collections agency. Paperwork only. No legal stamp, architectural approval, or demand letter as counsel.

## Back up this folder

This folder will fill with notes about how your shop works, plus a folder for each meeting, application, or pack. Copy the **whole folder** to a safe place on a regular schedule.
