# Work Item Rules

Rules are constraints and procedures specific to this venue job. Promote durable ones with **promote-facts-rules**.

**Format:**

```
### YYYY-MM-DD: [Prescriptive Title]
**Scope:** work-item
**Triggers:** none | write:doc | write:csv
**Captured:** YYYY-MM-DD
**Source:** [operator, export name, chat]
**Status:** [active | promoted-to-expert | archived]

**Rule:** Clear statement of what MUST be done
```

Work Item rules do not need `**Workflows:**` — they inherit this Work Item’s registry job.

Expert Role rules live in `facts/rules-shared.md`.
