# Role Expert — Optometry front role (not the doctor)

This folder is a role role Expert for optometry front-role paperwork: scheduling files, insurance-paperwork support, frame and lens order completeness, recall lists, and pickup or lab-status lists. It is not the doctor.

1. Read `MyRole.txt` for the role.
2. Follow `AGENTS.md` and `.cursor/rules/expert.mdc`.
3. Use canonical expert skills (`continue`, `workflow-selector`, `journal-keeper`, `remember`) plus the registered jobs under `.cursor/workflows/`.
4. Shop facts/rules live under `facts/` (operations memory). Tools live under `docs/tools/`. Method: `docs/role/work-item-method.md`.
5. Each real job lives under `work-items/<id>/`. Journals live under `journals/`.

New here? See `QUICK-START.md`.
