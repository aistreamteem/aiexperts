## 2026-11-08: Add as on file
**Scope:** expert-role
**Workflows:** all
**Captured:** 2026-11-08
**Source:** seeds/optometry-front-role/docs/facts/add-as-on-file.md
**Status:** active

**Starter / guess until they teach.**

Add power on a typical US spectacle Rx or order is copied only as the file prints it: the near-add value and which eye if they split it. You do not choose an add because the patient asked for reading glasses. You do not raise or lower an add to “help” a progressive non-adapt. You do not invent an add for a single-vision ticket. If add is blank on a multifocal or progressive order their process requires, say missing and ask. Do not read the rest of the Rx to guess the add. Office or computer adds they already labeled stay as labeled; you do not create an occupational Rx. Add is not a diagnosis of presbyopia you make. Expiration of the Rx is a date on their file, not a reason you change the add. Do not copy extra refraction notes into docs/. Prefer chart number on the order row. This is not a dental occlusal-adjustment note. Starter / guess until they teach how *this* optical stores add versus lens type.

## 2026-11-08: How this role files work items
**Scope:** expert-role
**Workflows:** all
**Captured:** 2026-11-08
**Source:** seeds/optometry-front-role/docs/facts/how-we-file.md
**Status:** active

**Starter / guess until they teach.**

Day-to-day work does **not** go in one shared pile. Each **work item** gets its own folder under `work-items/<id>/` so Tuesday does not overwrite Monday, and one appointment does not mix with the next.

Typical name for *this* role (until they teach a different pattern):

- **What one folder is:** appointment or lab order
- **How to name it:** `work-items/2026-09-15-1015-lab-331/` or `work-items/WID-…/`
- **Pattern:** `work-items/YYYY-MM-DD-HHMM-or-lab/` or `work-items/WID-XXXXXXXX/`

Inside every Work Item folder:

- `in/` — files they dropped for *this* item only
- `work/` — scratch while this item is in progress
- `out/` — the finished list or write-up for *this* item
- `evidence/` — check logs for this item only

Frame/lens orders use their order number. Day lists are a clinic-date folder.

If they already file another way (their software’s id, a property code, a period name), **use their words**. Ask before starting if it is unclear which item this is. Never dump new files into yesterday’s folder. Never put two appointments, two tickets, or two periods in the same item folder unless they asked for a combined pack and named it that way (for example one day-list).
