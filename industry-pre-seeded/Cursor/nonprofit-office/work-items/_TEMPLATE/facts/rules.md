# Work Item Rules

Rules are constraints, procedures, and patterns that MUST be followed during this nonprofit-office Work Item. They are prescriptive and violations should be logged in the journal.

See entry format in `facts/MEMORY-INDEX.md`.

**Format:**

```
### YYYY-MM-DD: [Label/Title]
**Scope:** work-item
**Triggers:** none | write:doc | write:csv
**Captured:** YYYY-MM-DD
**Source:** [Optional: operator, file name, chat]
**Status:** [active | promoted-to-expert | archived]

**Rule:** [statement]
```

**Note:** Work Item-level rules do NOT need a `**Workflows:**` field — they inherit the Work Item's workflow context.
