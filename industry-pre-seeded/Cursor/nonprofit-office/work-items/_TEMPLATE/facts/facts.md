# Work Item Facts

Facts are observations, data, and context specific to this nonprofit-office Work Item (this meeting, grant, gift batch, or restricted-fund question). They are informative, not prescriptive.

See entry format in `facts/MEMORY-INDEX.md`.

**Format:**

```
### YYYY-MM-DD: [Label/Title]
**Scope:** work-item
**Captured:** YYYY-MM-DD
**Source:** [Optional: operator, file name, chat]
**Status:** [active | promoted-to-expert | archived]

[Content with full formatting preserved]
```

**Note:** Work Item-level facts do NOT need a `**Workflows:**` field — they inherit the Work Item's workflow context.
