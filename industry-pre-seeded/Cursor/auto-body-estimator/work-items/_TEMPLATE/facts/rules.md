# Work Item Rules

Rules are constraints that MUST be followed on this assignment / RO / claim. Log violations in the journal.

**Format:**

```
### YYYY-MM-DD: [Label/Title]
**Scope:** work-item
**Captured:** YYYY-MM-DD
**Source:** [operator, DRP file they stored, …]
**Status:** [active | promoted-to-expert | archived]

**Rule:** [statement]

---
```

Work Item-level rules do NOT need a `**Workflows:**` field — they inherit this Work Item’s job.

For Expert Role-level rules (in `facts/rules-shared.md`), include `**Workflows:** all` and `**Triggers:** none` (or a role action token).
