# Rules — Shared (all workflows)

Cross-cutting shop rules that apply on every Work Item for this role. Entry format: see [MEMORY-INDEX.md](MEMORY-INDEX.md). Every rule needs a `**Triggers:**` line (`none` or a token the action hook can produce, currently `write:doc`).

Route new entries marked `Workflows: all` here. Role-specific operations rules stay in [rules-operations.md](rules-operations.md).
