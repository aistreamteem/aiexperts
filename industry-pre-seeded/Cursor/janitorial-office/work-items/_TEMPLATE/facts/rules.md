# Work Item Rules

Rules that MUST be followed for **this pack**. Violations go in the journal.

**Format:**

```markdown
### YYYY-MM-DD: [Label]
**Scope:** work-item
**Triggers:** none | write:file | write:sheet | write:csv | write:doc
**Captured:** YYYY-MM-DD
**Source:** [operator / file]
**Status:** active | promoted-to-expert | archived

**Rule:** [statement]
```

Work Item rules do not need `**Workflows:**`. Expert Role rules live in `facts/rules-shared.md` and `facts/rules-operations.md`.
