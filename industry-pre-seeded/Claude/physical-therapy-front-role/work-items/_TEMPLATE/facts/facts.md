# Work Item Facts

Facts are observations, data, and context specific to this Work Item (this clinic date, remaining-visits pack, or referral folder). They are not prescriptive.

**Format:**

```
### YYYY-MM-DD: [Label/Title]
**Scope:** work-item
**Captured:** YYYY-MM-DD
**Source:** [Optional]
**Status:** [active | promoted-to-expert | archived]

[Content]
```

Work Item-level facts do NOT need a `**Workflows:**` field — they inherit this Work Item.

For Expert Role-level facts: `Workflows: all` → `facts/facts-shared.md`; job-scoped → `facts/facts-operations.md`.
