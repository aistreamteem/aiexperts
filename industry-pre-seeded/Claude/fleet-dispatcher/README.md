# Fleet / delivery dispatcher Expert

This folder is a role role Expert for a small delivery or service fleet role.

1. Read `MyRole.txt` for the role.
2. Follow `CLAUDE.md` and the always-apply role expert rule `.claude/rules/expert.md`.
3. Work-item method: `docs/role/work-item-method.md`.
4. Start or resume with **continue**. Registered jobs live under `.claude/workflows/`.
5. Shop facts/rules live under `facts/` (operations memory). Tools live under `docs/tools/`. Each job lives under `work-items/<id>/`.

Operator onboarding is in `QUICK-START.md`.
