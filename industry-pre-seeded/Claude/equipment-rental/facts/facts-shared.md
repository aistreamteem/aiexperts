### 2026-11-08: Accessory kit
**Scope:** expert-role
**Workflows:** all
**Captured:** 2026-11-08
**Source:** seeds/equipment-rental/docs/facts/accessory-kit.md
**Status:** active

**Starter / guess until they confirm this yard.**

An accessory kit is the extra pieces that travel with a class or a serial: forks, buckets, pads, hitches, fire extinguishers, lift-gate remotes. Typical US SMB fleet files have a kit tab or a serialized-kit list. Outgoing inspection should confirm the kit they said goes with the unit. You list kit lines from their file. You do not invent a kit so the contract looks complete. You do not invent a kit rate; kit dollars come from the rate file if they price extras. Substituting a unit means checking the substitute’s kit, not assuming the same forks. Return inspection marks missing kit as lost-item. Starter until they confirm which kits *this* yard always sends and which are on request. Manuals and CO2 bottles, if they track them, sit on the same list. You do not diagnose a leaking hose as a mechanic; you note the inspection words. Gate-safe accessories still need their list, not an engineering add.

### 2026-11-08: How this role files work items
**Scope:** expert-role
**Workflows:** all
**Captured:** 2026-11-08
**Source:** seeds/equipment-rental/docs/facts/how-we-file.md
**Status:** active

**Starter / guess until they confirm this yard.**

Day-to-day work does **not** go in one shared pile. Each **work item** gets its own folder under `work-items/<id>/` so Tuesday does not overwrite Monday, and one appointment does not mix with the next.

Typical name for *this* role (until they confirm a different pattern):

- **What one folder is:** contract or reservation
- **How to name it:** `work-items/2026-09-15-contract-331/`
- **Pattern:** `work-items/YYYY-MM-DD-contract/`

Inside every Work Item folder:

- `in/` — files they dropped for *this* item only
- `work/` — scratch while this item is in progress
- `out/` — the finished list or pack for *this* item
- `evidence/` — check logs for this item only

Outgoing and return for that contract stay together. Fleet counts can be a named day folder. Journals for the item live under `journals/work-items/<id>/`.

If they already file another way (their software’s id, a property code, a period name), **use their words**. Ask before starting if it is unclear which item this is. Never dump new files into yesterday’s folder. Never put two appointments, two tickets, or two periods in the same item folder unless they asked for a combined pack and named it that way (for example one day-list).
