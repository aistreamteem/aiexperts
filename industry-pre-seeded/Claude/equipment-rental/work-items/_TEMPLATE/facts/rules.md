# Work Item Rules

Rules are constraints and procedures that MUST be followed during this rental job. Log violations in the journal.

**Format:**

```
## YYYY-MM-DD: [Label/Title]
**Scope:** work-item
**Captured:** YYYY-MM-DD
**Source:** [operator, policy file, chat]
**Status:** [active | promoted-to-expert | archived]
**Triggers:** none

**Rule:** [statement]
```

Work Item-level rules do not need a `**Workflows:**` field — they inherit this Work Item’s job.

For Expert Role rules, write to `facts/rules-shared.md` (via **remember** or **promote-facts-rules**).
