# Work Item Facts

Facts are observations and context specific to this assignment / RO / claim. They inform the pack but are not prescriptive.

**Format:**

```
### YYYY-MM-DD: [Label/Title]
**Scope:** work-item
**Captured:** YYYY-MM-DD
**Source:** [operator, assignment PDF, estimate export, …]
**Status:** [active | promoted-to-expert | archived]

[Content]

---
```

Work Item-level facts do NOT need a `**Workflows:**` field — they inherit this Work Item’s job.

For Expert Role-level facts (in `facts/facts-shared.md`), include `**Workflows:** all`.
