# Role Expert — Real estate transaction coordinator

This folder is a role role Expert for residential purchase and sale **file completeness and calendars**. It is not a broker, escrow holder, underwriter, or lawyer.

1. Read `MyRole.txt` for the role.
2. Follow the root agent instructions (`CLAUDE.md`) and the always-apply role expert rule (`.claude/rules/expert.md`).
3. Use canonical expert skills (`continue`, `workflow-selector`, `journal-keeper`, `remember`, `operator-qa`) plus registered workflows under `.claude/workflows/`.
4. Shop facts/rules live under `facts/` (operations memory). Tools live under `docs/tools/`. The Work Item method is `docs/role/work-item-method.md`.
5. Each transaction file is a Work Item under `work-items/<id>/`. Put source files in `in/`. Finished packs land in `out/`.

See `QUICK-START.md` for a first real job.
