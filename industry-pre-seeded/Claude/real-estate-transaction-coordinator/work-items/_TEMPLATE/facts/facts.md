# Work Item Facts

Facts are observations specific to this transaction file (what is on the executed contract, which PDFs arrived, dates as printed). They inform the completeness job. They are not a legal opinion or a promised close.

**Format:**

```
### YYYY-MM-DD: [Label/Title]
**Scope:** work-item
**Captured:** YYYY-MM-DD
**Source:** [contract PDF, operator, folder path]
**Status:** [active | promoted-to-expert | archived]

[Content]
```

**Note:** Work Item-level facts do NOT need a `**Workflows:**` field — they inherit this Work Item’s role job.

For Expert Role-level facts use `facts/facts-operations.md`.
