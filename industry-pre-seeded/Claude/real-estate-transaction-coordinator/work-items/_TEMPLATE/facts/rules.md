# Work Item Rules

Rules are constraints that MUST be followed for this transaction Work Item (shop forms they named for this file, extra never-dos). Violations should be logged in the journal.

**Format:**

```
### YYYY-MM-DD: [Label/Title]
**Scope:** work-item
**Captured:** YYYY-MM-DD
**Source:** [Optional]
**Status:** [active | promoted-to-expert | archived]
**Triggers:** none

**Rule:** [statement]
```

Work Item-level rules do not need a `**Workflows:**` field — they inherit this Work Item’s role job.

For Expert Role-level rules use `facts/rules-operations.md`. Completeness is not an approval, a close, or a legal opinion.
