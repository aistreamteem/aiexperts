# Memory System Index

Quick navigation for this optometry front-role Expert. Load only what the current pack needs.

---

## Two axes: browsing and triggers

1. **Workflow axis** (this file) — which files to load for this role.
2. **Trigger axis** ([TRIGGER-INDEX.md](TRIGGER-INDEX.md)) — action-time surfacing via `.claude/hooks/inject_rules_on_action.py`. Regenerated by `python scripts/memory/build_trigger_index.py`.

This role does **not** use developer or production-incident memory files.

## Entry format reference

### Fact

```markdown
### YYYY-MM-DD: Descriptive Title

**Scope:** expert-role
**Workflows:** all | day-list | eligibility-screenshot | ...
**Captured:** YYYY-MM-DD
**Source:** <where this came from>
```

### Rule

```markdown
### YYYY-MM-DD: Prescriptive Action Title

**Scope:** expert-role
**Workflows:** all | day-list | ...
**Triggers:** write:doc | write:csv | none
**Captured:** YYYY-MM-DD
**Source:** <where this came from>

**Rule:** Clear statement of what MUST be done
```

### Usage

1. Always load this index first.
2. Load operations facts + rules for every Work Item on this role.
3. Filter entries by `**Workflows:**` when a job id is set; include `all`.
4. Do not load developer or incident files; they are not this role.

**Maintenance:** After adding facts/rules, keep this index honest. For health metrics see [HOW-MEMORY-LOADING-WORKS.md](HOW-MEMORY-LOADING-WORKS.md).
