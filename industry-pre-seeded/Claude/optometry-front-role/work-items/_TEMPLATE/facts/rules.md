# Work Item Rules

Rules are constraints, procedures, and patterns that MUST be followed during this Work Item. They are prescriptive and violations should be logged in the journal.

**Format:**

```
### YYYY-MM-DD: [Label/Title]
**Scope:** work-item
**Triggers:** none
**Captured:** YYYY-MM-DD
**Source:** [operator, filename, chat]
**Status:** [active | promoted-to-expert | archived]

**Rule:** [statement]
```

Work Item-level rules do NOT need a `**Workflows:**` field — they inherit this job. Include `**Triggers:**` so promoted copies keep action tags.

For Expert Role-level rules use `facts/rules-operations.md` (see `facts/MEMORY-INDEX.md`).
