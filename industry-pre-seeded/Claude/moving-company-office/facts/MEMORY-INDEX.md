# Memory System Index

Quick navigation for this moving-company office Expert. Load only the files you need.

---

## Two Axes: Workflow (browsing) and Triggers (action)

Rules are indexed on **two orthogonal axes**:

1. **Workflow axis** (this file) — which memory files to load for a role job.
2. **Trigger axis** ([TRIGGER-INDEX.md](TRIGGER-INDEX.md)) — action-time surfacing via `.claude/hooks/inject_rules_on_action.py`. Regenerated by `python scripts/memory/build_trigger_index.py`.

---

## Pre-seeded role

**Role title:** Moving company office

**Seed id:** `moving-company-office`

**Work-item method:** `docs/role/work-item-method.md`

Always load the **shared** pair, then the **operations** pair:

- [facts-shared.md](facts-shared.md) / [rules-shared.md](rules-shared.md) — `Workflows: all` entries
- [facts-operations.md](facts-operations.md) — rate files, inventory, crew, trucks, scale tickets, claims routing, and related shop notes
- [rules-operations.md](rules-operations.md) — never invent weight/cube, rates from their file, claims route not adjust, one Work Item one folder, and related constraints

### When to load

**When to use:** Any registered job (estimate, inventory, crew day, truck calendar, materials, delivery windows, weigh tickets, claims).

**Load these files:**

1. This index
2. `facts-shared.md` + `rules-shared.md`
3. `facts-operations.md` + `rules-operations.md`
4. Active Work Item `work-items/<id>/facts/facts.md` and `rules.md` when present

This expert does **not** load developer or production-incident memory files. Those are not this role.

### Registered workflows

See `.claude/workflows/workflow-registry.json`. Default: `estimate-from-rate-file`.

## Entry Format Reference

### Fact

```markdown
### YYYY-MM-DD: Descriptive Title
**Scope:** expert-role
**Workflows:** all | estimate-from-rate-file | crew-day | …
**Captured:** YYYY-MM-DD
**Source:** <where this came from>
**Status:** active

Descriptive content…
```

### Rule

```markdown
### YYYY-MM-DD: Prescriptive Action Title
**Scope:** expert-role
**Workflows:** all | estimate-from-rate-file | …
**Triggers:** write:csv | write:doc | write:estimate | none
**Captured:** YYYY-MM-DD
**Source:** <where this came from>
**Status:** active

**Rule:** Clear statement of what MUST be done
```

## Usage

1. Load this index
2. Load shared facts + rules, then operations facts + rules
3. Load Work Item memory for the current move
4. Follow rules; treat unconfirmed starter notes as guesses until the operator confirms

**Maintenance:** Route `Workflows: all` into the shared pair; job-specific captures into operations. For health metrics see [HOW-MEMORY-LOADING-WORKS.md](HOW-MEMORY-LOADING-WORKS.md).
