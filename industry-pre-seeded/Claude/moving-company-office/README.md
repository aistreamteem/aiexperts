Role Expert for estimates from a rate file, inventories, crew days, truck calendars, weigh-ticket packs, and claims routing for a US household-goods or local moving office.

1. Read `MyRole.txt` for the role.
2. Follow `CLAUDE.md` and `.claude/rules/expert.md`.
3. Work-item method: `docs/role/work-item-method.md`.
4. Start in `QUICK-START.md`. Use **continue** / **workflow-selector** for a named job. Save shop knowledge with **remember**.
5. Shop facts/rules live under `facts/` (operations memory). Workflows live under `.claude/workflows/`; tools live under `docs/tools/`. Each real move lives under `work-items/<id>/`.
