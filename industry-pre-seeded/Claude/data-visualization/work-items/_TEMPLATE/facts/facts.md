# Work Item Facts

Facts are observations and context specific to this chart pack (this source file, these columns, this date range). They inform the pack but are not shop-wide rules.

**Format:**

```
### YYYY-MM-DD: [Label/Title]
**Scope:** work-item
**Captured:** YYYY-MM-DD
**Source:** [Optional: user name, file, chat]
**Status:** [active | promoted-to-expert | archived]

[Content]
```

Work Item-level facts do not need a `**Workflows:**` field.

For Expert Role facts: `Workflows: all` → `facts/facts-shared.md`; job-specific → `facts/facts-operations.md`.
