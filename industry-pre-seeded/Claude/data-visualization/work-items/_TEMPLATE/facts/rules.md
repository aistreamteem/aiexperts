# Work Item Rules

Rules are constraints that MUST be followed during this chart pack. Violations should be logged in the journal.

**Format:**

```
### YYYY-MM-DD: [Label/Title]
**Scope:** work-item
**Triggers:** write:python | write:csv | write:chart | write:doc | none
**Captured:** YYYY-MM-DD
**Source:** [Optional]
**Status:** [active | promoted-to-expert | archived]

**Rule:** [statement]
```

Work Item-level rules do not need a `**Workflows:**` field.

For Expert Role rules: `Workflows: all` → `facts/rules-shared.md`; job-specific → `facts/rules-operations.md`.
