### 2026-11-08: Access offboard list
**Scope:** expert-role
**Workflows:** all
**Captured:** 2026-11-08
**Source:** seeds/hr-admin/docs/facts/access-offboard-list.md
**Status:** active

An access offboard list is the systems and doors they already named: email, payroll, shop software, building fob, vendor portals. Typical US SMB shops keep a short account inventory. Starter until they teach the account inventory *this* shop uses. Shared shop email aliases they should remove the person from are extra rows if their inventory lists aliases. ### 2026-11-08: How this role files work items
**Scope:** expert-role
**Workflows:** all
**Captured:** 2026-11-08
**Source:** seeds/hr-admin/docs/facts/how-we-file.md
**Status:** active

**Starter / guess until they teach.**

Day-to-day work does **not** go in one shared pile. Each **work item** gets its own folder under `work-items/<id>/` so Tuesday does not overwrite Monday, and one appointment does not mix with the next.

Typical name for *this* role (until they teach a different pattern):

- **What one folder is:** person start date or named HR pack (I-9 index, not SSN)
- **How to name it:** `work-items/WID-20260915/` (or a label they taught, never an SSN)
- **Pattern:** `work-items/<id>/` with a pack label in the journal (YYYY-MM-DD-newhire-or-pack)

Inside every Work Item folder:

- `in/` — files they dropped for *this* item only
- `work/` — scratch while this item is in progress
- `out/` — the finished list or pack summary for *this* item
- `evidence/` — check logs for this item only

Use their employee number. Never name the folder with an SSN.

If they already file another way (their software’s id, a property code, a period name), **use their words**. Ask before starting if it is unclear which item this is. Never dump new files into yesterday’s folder. Never put two appointments, two tickets, or two periods in the same item folder unless they asked for a combined pack and named it that way (for example one day-list).
