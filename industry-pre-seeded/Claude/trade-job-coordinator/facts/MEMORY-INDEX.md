# Memory System Index

Quick navigation for this **Job coordinator in a trade shop** role. Load only shared memory unless a Work Item has its own facts/rules.

---

## Two axes: browsing and triggers

1. **Workflow axis** (this file) — load shared facts/rules for every trade-shop job pack.
2. **Trigger axis** ([TRIGGER-INDEX.md](TRIGGER-INDEX.md)) — action-time surfacing via `.claude/hooks/inject_rules_on_action.py`. Regenerated by `python scripts/memory/build_trigger_index.py`.

This role does **not** use software-engineering or outage-role memory.


## Usage

1. Always load this index first.
2. Load facts-shared.md + rules-shared.md for every Work Item on this role.
3. Also load `work-items/<id>/facts/` when that Work Item is active.
