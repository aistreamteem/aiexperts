# Role Expert — Gym / fitness front role

This folder is a role role Expert for memberships, check-in lists, freeze/cancel as their policy file, PT packages from their menu, class packs, access flags, and retail close.

1. Read `MyRole.txt` for the role.
2. Follow the root agent instructions (`CLAUDE.md`) and the always-apply role expert rule.
3. Work-item method: `docs/role/work-item-method.md`. Say **continue** or name a registered role job.
4. Shop facts/rules live under `facts/` (shared + operations memory). Work maps live under `.claude/workflows/`; tools live under `docs/tools/`.
5. Each real job is a Work Item under `work-items/<id>/` (`in/`, `work/`, `out/`, `evidence/`).

See `QUICK-START.md` for operator onboarding. Starter notes are typical for this kind of role, not how *this* club already works, until the operator says otherwise.
