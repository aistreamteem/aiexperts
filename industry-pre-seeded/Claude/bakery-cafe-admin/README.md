# Bakery / cafe production office Expert

This folder is a role Expert for a bakery or bakery-cafe production office: bake lists, case pars, wholesale standing packs, custom cake boards, receiving shorts, allergen indexes, holiday bake-ups, ingredient pars, and stale/waste recaps.

1. Read `MyRole.txt` for the role.
2. Follow `CLAUDE.md` and `.claude/rules/expert.md`.
3. Work-item method: `docs/role/work-item-method.md`.
4. Operator onboarding: `QUICK-START.md`.
5. Shop facts/rules live under `facts/` (operations memory). Jobs live under `.claude/workflows/`. Tools live under `docs/tools/`.
6. Each real job is a Work Item under `work-items/<id>/`. Journals live under `journals/`.

Starter notes are typical-practice guesses until this shop confirms them. Quantities quote their files. Shorts, stales, and missing formulas stay visible.
