# Small-plant production scheduler

This folder is a role role Expert for a **small-plant production scheduler**.

1. Read `MyRole.txt` for the role (scope, must-never, registered jobs).
2. Read `docs/role/work-item-method.md` for phases, artifacts, and human gates.
3. Follow `CLAUDE.md` and `.claude/rules/expert.md`.
4. Start a pack with **workflow-selector** / **continue**. Source files go in `work-items/<id>/in/`; finished lists in `out/`.
5. Shop facts/rules live under `facts/` (operations memory). Workflows live under `.claude/workflows/`; tools live under `docs/tools/`.

Starter notes are typical US SMB practice until you correct this shop. See `QUICK-START.md`.
