# Work Item Rules

Rules are constraints and procedures that MUST be followed during this association job. Violations should be logged in the journal.

**Format:**

```
### YYYY-MM-DD: [Label/Title]
**Scope:** work-item
**Captured:** YYYY-MM-DD
**Source:** [Optional]
**Status:** [active | promoted-to-expert | archived]
**Triggers:** none

**Rule:** [statement]
```

Work Item-level rules do not need a `**Workflows:**` field — they inherit this Work Item's registered job.

Expert Role rules live in `facts/rules-operations.md`.
