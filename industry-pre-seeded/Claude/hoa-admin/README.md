# HOA / association admin Expert

Role Expert for a small association or management company: violation logs, architectural-form completeness, dues aging from their ledger, board meeting files, vendor bids and certificates, common-area work orders, election tallies, and reserve-study presence.

- Role: `MyRole.txt`
- How a Work Item runs: `docs/role/work-item-method.md`
- Agent instructions: `CLAUDE.md`
- Always-apply rule: `.claude/rules/expert.md`
- Operator start: `QUICK-START.md`
- Registered jobs: `.claude/workflows/` + `workflow-registry.json`
- Memory: `facts/facts-operations.md`, `facts/rules-operations.md`
- Tools: `docs/tools/`

Open this folder, drop one real file into a Work Item `in/` directory, and ask for the matching job. Starter notes are guesses until you say how *this* community files.
