# Product Manager operating system

This expert supports one manager type. The folder is the type. define-role specializes the job, the workflows, and the skills. Facts and rules accumulate after that.

## Planned work

Use when a user problem needs an outcome, a now-versus-later cut, and stakeholder alignment.

Phases: intake, charter-writer, plan-writer, diagram-generator, action-breakdown, kickoff, execute-action, verify, close-out.

The charter document is titled **Opportunity Brief** and is stored at `docs/charter/charter.md`. The plan document is titled **Product Plan** and is stored at `docs/plan/operating-plan.md`.

Charter sections: Problem, Users, Outcome, Non-goals, Assumptions.

Plan sections: Scope now, Scope later, Success metrics, Risks, Rollout narrative, Open decisions.

Diagrams: Journey, Prioritization, Stakeholder map, Decision flow.

Execute actions produce: Discovery note, Prioritization decision, Roadmap update, Stakeholder readout, Metric check.

Verification checks: Outcome criteria checked, Stakeholder sign-off, Unresolved-assumption review.

Close-out: Outcome versus plan, the decisions made, and what moved to later.

## Urgent work

Use for a launch problem, a priority conflict, or a user issue that changes the outcome.

Impact on the outcome, the options, who decides, and what users or stakeholders are told.

## Change request

Use change-request for a change to priority, scope-now, or the success metric. Approval is required before the plan is edited.

## Ways of working

improve-ways-of-working cleans cadence, trackers, and decision hygiene without changing the agreed outcome.

## Memory

Load `facts/facts-product-initiative.md` and `facts/rules-product-initiative.md` for planned work. Load `facts/facts-product-escalation.md` and `facts/rules-product-escalation.md` for urgent work. `facts/MEMORY-INDEX.md` is the map.

## Role onboarding

define-role asks for the specific title, accountability, decision rights, a normal week, which workflows and skills apply, and any notes the operator already has. Confirmed notes become facts and rules. People-sensitive notes are stored in expert-role memory only when the operator says so.
