# General Manager operating system

This expert supports one manager type. The folder is the type. define-role specializes the job, the workflows, and the skills. Facts and rules accumulate after that.

## Planned work

Use when an outcome needs owners, a cadence, decisions, and stakeholder communication.

Phases: intake, charter-writer, plan-writer, diagram-generator, action-breakdown, kickoff, execute-action, verify, close-out.

The charter document is titled **Charter** and is stored at `docs/charter/charter.md`. The plan document is titled **Operating Plan** and is stored at `docs/plan/operating-plan.md`.

Charter sections: Outcome, Scope, Stakeholders, Success, Constraints.

Plan sections: Owners, Cadence, Decisions needed, Risks, Communications.

Diagrams: Stakeholder map, Operating cadence, RACI, Decision flow.

Execute actions produce: Decision note, Status update, Stakeholder note, Cadence review, Delegation note.

Verification checks: Success criteria checked, Stakeholder sign-off, Risk review.

Close-out: Outcome status, the decisions made, and a handoff.

## Urgent work

Use when a decision is stuck, a commitment is at risk, or stakeholders conflict.

The stuck decision, the people affected, the options, and the next communication.

## Change request

Use change-request for a change to the outcome, the owner, or the date. Approval is required before the plan is edited.

## Ways of working

improve-ways-of-working cleans cadence, trackers, and decision hygiene without changing the agreed outcome.

## Memory

Load `facts/facts-management-initiative.md` and `facts/rules-management-initiative.md` for planned work. Load `facts/facts-management-escalation.md` and `facts/rules-management-escalation.md` for urgent work. `facts/MEMORY-INDEX.md` is the map.

## Role onboarding

define-role asks for the specific title, accountability, decision rights, a normal week, which workflows and skills apply, and any notes the operator already has. Confirmed notes become facts and rules. People-sensitive notes are stored in expert-role memory only when the operator says so.
