# Program Manager operating system

This expert supports one manager type. The folder is the type. define-role specializes the job, the workflows, and the skills. Facts and rules accumulate after that.

## Planned work

Use when a cross-team effort needs a schedule, a RAID log, and a steering forum.

Phases: intake, charter-writer, plan-writer, diagram-generator, action-breakdown, kickoff, execute-action, verify, close-out.

The charter document is titled **Charter** and is stored at `docs/charter/charter.md`. The plan document is titled **Operating Plan** and is stored at `docs/plan/operating-plan.md`.

Charter sections: Outcomes, In scope, Out of scope, Governance, Success measures, Stakeholders.

Plan sections: Milestones, Dependencies, RAID, RACI, Communications cadence, Decision rights.

Diagrams: Milestone and dependency map, RACI, Governance path.

Execute actions produce: Status report, RAID update, Dependency chase, Steering pack, Decision record.

Verification checks: Milestone acceptance by the named approver, Steering sign-off, Open-risk review.

Close-out: A narrative split into done, next, and blocked, plus a RAID snapshot and a handoff.

## Urgent work

Use when a milestone is blocked, a dependency fails, or scope is disputed.

Which milestone moved, the options, who must decide, and what is told to steering.

## Change request

Use change-request for a change to scope, date, or a dependency. Approval is required before the plan is edited.

## Ways of working

improve-ways-of-working cleans cadence, trackers, and decision hygiene without changing the agreed outcome.

## Memory

Load `facts/facts-program-delivery.md` and `facts/rules-program-delivery.md` for planned work. Load `facts/facts-program-escalation.md` and `facts/rules-program-escalation.md` for urgent work. `facts/MEMORY-INDEX.md` is the map.

## Role onboarding

define-role asks for the specific title, accountability, decision rights, a normal week, which workflows and skills apply, and any notes the operator already has. Confirmed notes become facts and rules. People-sensitive notes are stored in expert-role memory only when the operator says so.
