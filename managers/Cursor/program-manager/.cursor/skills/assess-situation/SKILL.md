# Assess situation

Write `docs/escalations/assessment.md`.

This escalation must cover: Which milestone moved, the options, who must decide, and what is told to steering.

1. Ask what is known and what is still unknown. Unknowns that block the assessment are blocking questions.
2. Do not accept a milestone yourself when a named approver is recorded.
3. Set next action to "run analyze-impact".
